# Contributing

Read AGENTS.md and INSTALL.md. Keep changes scoped and run the checks in .github/workflows/ci.yml. Use a disposable database for tests. Include behavior, validation and remaining external dependencies in pull requests. Do not include real credentials, deployment addresses, user data or generated production assets.

The repository has no newly imposed license grant for bundled third-party assets or model weights. Preserve upstream attribution and obtain the relevant permissions before redistribution. See THIRD_PARTY.md.
